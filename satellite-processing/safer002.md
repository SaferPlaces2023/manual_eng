# 🛠️ Safer002

The "Safer002" function relies on algorithms developed for generating a high-resolution digital elevation model (DEM/DTM) of the area of interest. The Safer002 module does not require any user interaction; its execution is triggered by an internal process. During the project creation phase, it is possible to select "SAFER002/DEM" as a dataset, and the output of the Safer002 function will be used to generate the digital model of the area of interest.
