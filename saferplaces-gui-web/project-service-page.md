# 💻 Project/Service Page

{% hint style="info" %}
After creating a new project, you will see the project added to your personal dashboard in the “_My Projects_” section.

Here, you can view a complete list of all your projects along with the pre-existing ones from SaferPlaces.

These include various projects activated in specific areas or cities, allowing you to have a detailed and organized overview of all the projects you are working on or are interested in.

Thanks to this feature, you can easily manage and monitor active initiatives, facilitating access and interaction with each project directly from your user page.
{% endhint %}

<figure><img src="../.gitbook/assets/Screenshot 2024-10-09 at 22.55.19.png" alt=""><figcaption><p>Pagina Personale con i progetti attivati</p></figcaption></figure>

Clicking on the icon of the newly created project, the user accesses the specific workspace for that project. By doing so, they will have access to all the functionalities and tools necessary to get started. The following figure shows the main interface of the platform after accessing the project.

<figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption><p>Interfaccia grafica per lavorare in un progetto creato</p></figcaption></figure>

{% hint style="info" %}


The web application consists of:

* A mapping area in the center of the screen.
* A sidebar on the right with all the background spatial layers (“_layers_”) generated at the time of project creation ( [right-sidebar.md](right-sidebar.md "mention"))
* A top bar with basic tools and specific tools for simulations. ( [top-bar.md](top-bar.md "mention"))
* A sidebar on the left ( [left-sidebar.md](left-sidebar.md "mention"))
{% endhint %}
