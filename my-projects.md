# 🚀 My Projects

By logging in, users can access their personal page, which includes both previously generated projects and the ability to generate new areas/cities to activate the Saferplaces Platform.

<figure><img src=".gitbook/assets/Screenshot 2024-10-09 at 22.55.19.png" alt=""><figcaption><p>Pagina Personale - My Projects</p></figcaption></figure>

{% hint style="info" %}
Click on the 3 lines in the top right corner to access:

* User Profile
* User Profile Settings
* Cloud resources usage
* Logout
{% endhint %}

<figure><img src=".gitbook/assets/Screenshot 2024-10-09 at 22.58.01.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
By clicking the three dots in the top right corner of the project name, you can:

* Rename the project
* Duplicate the project
* Delete the project
{% endhint %}
